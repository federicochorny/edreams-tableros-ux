# eDreams bajo la lupa · Grupo 1

Tableros de evaluación de eDreams para la materia Diseño y experiencia de usuario (UdeSA 2026).

- **Leyes UX:** las 14 leyes de la ficha de la cátedra, con cumple/rompe, captura y explicación.
- **Heurísticas de Nielsen:** las 10 heurísticas, con severidad de 0 a 4, captura, explicación e impacto.
- **Task flows y user flows:** cinco tareas priorizadas, diagramadas tal como funcionan hoy.

Sitio estático (HTML, CSS y JS, sin build). Para verlo en local, abrí `index.html`. Para publicarlo, importá el repositorio en Vercel con «Framework Preset: Other».

| Archivo | Contenido |
|---|---|
| `data.js` | Textos de las leyes y heurísticas |
| `flujos.js` | Task flows y user flows (Mermaid) |

El registro de prompts está en el documento `prompts_leyes_heuristicas` del Drive del grupo.
